Buy clothes with better size confidence.

FitCheck stores a user's body measurements, compares them with clothing item size charts, and leaves a dedicated space for a future 3D body model that can preview how garments fit.

1. Account Create a quick local prototype account or log back in.
2. Measurements Save body sizing data to the browser using localStorage.
3. Fit check Compare garment measurements with the user's body profile.
Prototype only: passwords are stored in browser localStorage, not a secure database.
